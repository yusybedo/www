# موقع العقارات المميزة

موقع إلكتروني تفاعلي باللغة العربية لعرض العقارات والمشاريع الاستثمارية مع لوحة تحكم إدارية كاملة.

## ⚠️ تنبيه أمني مهم
**هذا المشروع في وضع التطوير والتجربة.** نظام المصادقة الحالي غير آمن للإنتاج. **يرجى قراءة [SECURITY_NOTICE.md](./SECURITY_NOTICE.md) قبل النشر.**

## المميزات

- 🏠 عرض العقارات والمشاريع الاستثمارية
- 📝 مدونة للأخبار والمقالات العقارية
- 🔍 نظام بحث وفلترة متقدم
- 📱 تصميم متجاوب 100% (موبايل، تابلت، كمبيوتر)
- 🎨 تصميم RTL كامل للغة العربية
- 🔐 لوحة تحكم إدارية محمية
- ✏️ نظام CRUD كامل لإدارة المحتوى
- 🔥 Firebase كقاعدة بيانات
- 📧 نموذج اتصال تفاعلي

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (Vanilla)
- Firebase (Firestore)
- Google Fonts (خط Tajawal العربي)

## الصفحات

1. **الصفحة الرئيسية** - عرض العقارات والمشاريع المميزة
2. **العقارات** - جميع العقارات مع نظام بحث وفلترة
3. **المشاريع** - عرض المشاريع الاستثمارية
4. **المدونة** - المقالات والأخبار العقارية
5. **من نحن** - معلومات عن الشركة
6. **اتصل بنا** - نموذج تواصل
7. **لوحة التحكم** - إدارة كاملة للمحتوى

## لوحة التحكم

### تسجيل الدخول
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**⚠️ ملاحظة أمنية مهمة:**
- نظام المصادقة الحالي بسيط ومناسب للتطوير والاختبار فقط
- للإنتاج: يُنصح بشدة بتفعيل Firebase Authentication
- راجع ملف `DEPLOYMENT_GUIDE.md` لخطوات تحسين الأمان

### الوظائف
- إضافة/تعديل/حذف العقارات
- إضافة/تعديل/حذف المشاريع
- إضافة/تعديل/حذف المقالات
- عرض رسائل التواصل
- تحديد العناصر المميزة لعرضها في الصفحة الرئيسية

## النشر على Netlify

1. قم برفع المشروع على GitHub
2. اربط المستودع مع Netlify
3. انشر الموقع مباشرة

أو استخدم Netlify CLI:
```bash
netlify deploy --prod
```

## Firebase Configuration

المشروع مُعد مسبقاً بإعدادات Firebase. يمكنك تغيير الإعدادات في ملف `js/firebase-config.js`
